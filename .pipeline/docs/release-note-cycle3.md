# 릴리즈 노트 — 모바일 경매 하단 탭 네비게이션 재설계 (3차)

- 작성일: 2026-07-03 (경매 당일)
- 대상: 모바일 관전자, 모바일 팀장(캡틴). 데스크톱/관리자(마스터) 뷰는 영향 없음.
- 배포 상태: **미배포** — 아직 원격 저장소로 push되지 않았습니다. 사용자 확인 후 push하면 Vercel이 프론트엔드를 자동 배포합니다(백엔드 변경 없음).

## 무엇이 좋아졌나

### 1. 모바일 화면이 "위에서 아래로 쌓인 페이지"에서 "앱처럼 탭으로 전환되는 화면"으로 바뀌었습니다
기존 모바일 관전자/팀장 화면은 매물 카드 → 채팅 → 팀 현황을 세로로 나열해 스크롤해야 했습니다. 이제 화면 하단에 "경매" / "현황" 두 개의 탭바가 고정되고, 탭을 눌러 화면 자체를 전환하는 방식으로 바뀌었습니다. 페이지 자체 스크롤은 더 이상 발생하지 않습니다.

### 2. "경매" 탭 — 방송 스테이지처럼 재구성된 HUD
상단에 현재 매물 초상화, 현재가 숫자, 입찰 선두, 마감까지 남은 시간을 보여주는 도화선 타이머 바, 최근 입찰 2~3건이 흐르는 컴팩트 티커가 고정 배치되고, 그 아래로 채팅이 남은 공간 전부를 채웁니다. 팀장 화면에서는 스테이지와 채팅 사이에 입찰 버튼이 배치됩니다.

### 3. "현황" 탭 — 팀 카드를 언제든 스크롤로 확인
팀별 로스터와 잔여 포인트를 보여주는 팀 카드 목록을 탭 하나로 전환해 확인할 수 있습니다. 경매 진행 중 팀 상황이 궁금할 때만 탭을 넘기면 되고, 다시 "경매" 탭으로 돌아오면 채팅 화면 그대로입니다.

### 4. 탭을 넘나들어도 끊기지 않습니다
- 채팅 입력창에 쓰던 내용과 스크롤 위치는 "현황" 탭에 다녀와도 그대로 유지됩니다.
- "현황" 탭을 보고 있는 동안 입찰이나 낙찰이 발생해도 관련 효과음은 정상적으로 재생됩니다.
- 탭 전환은 화면 이동이 아니라 화면 안에서 즉시 바뀌는 방식이라, 채팅/타이머 갱신이 끊기지 않습니다.

### 5. 팩오프닝/전설급 연출/도화선 타이머는 그대로 유지됩니다
2차 사이클에서 만든 매물 공개 카드팩 연출, 전설급 매물 화면 플래시, 콤보 흔들림, 도화선 불꽃 타이머는 새 스테이지 크기에 맞춰 축소된 강도로 그대로 재생됩니다.

### 6. 데스크톱 화면은 전혀 바뀌지 않았습니다
이번 변경은 모바일(`lg` 미만) 화면에만 적용되며, PC/노트북 등 큰 화면에서 보는 경매 화면은 기존과 100% 동일합니다.

## 접근성 및 안정성
- "동작 줄이기(prefers-reduced-motion)" 설정 환경에서는 이전과 동일하게 카드 플립, 흔들림, 파티클, 티커 등장 애니메이션이 생략되거나 정적으로 대체됩니다.
- 개발 과정 코드 리뷰에서 모바일 화면 전환 시 전설급 매물 공개 화면 플래시가 두 번 겹쳐 보이는 결함을 발견해 배포 전 수정했습니다(사용자에게 노출되지 않았습니다).

## 참고
- 이번 릴리즈는 프론트엔드 전용이며 백엔드는 변경되지 않았습니다.
- 신규 npm 패키지 도입 없음(기존 Tailwind CSS, framer-motion만 사용).
- 관리자(마스터) 화면은 이번 스코프에서 제외되어 기존과 동일합니다.
- "매물" 탭(매물 풀 현황)과 낙찰 시 팀보드로 카드가 날아가는 모바일 연출은 이번 사이클에서는 만들지 않았습니다(우선순위가 낮아 다음 사이클 후보로 남겨둡니다).
