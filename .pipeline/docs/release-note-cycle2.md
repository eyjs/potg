# 릴리즈 노트 — 경매 인터랙션 고도화 2차 (팩 오프닝 / 콤보 / 도화선 타이머 / 골든카드 flight-in)

- 작성일: 2026-07-03
- 대상: 경매 참여자(캡틴), 마스터, 관전자(모바일 포함) 전원
- 배포 상태: **미배포** — 아직 원격 저장소로 push되지 않았습니다. 사용자 확인 후 push하면 Vercel이 자동으로 프론트엔드를 배포합니다(백엔드 변경 없음, 로컬 Docker 운영 백엔드는 이번 릴리즈와 무관).

## 무엇이 좋아졌나

### 1. 매물 공개 = 카드팩 오프닝 연출
새 매물이 등장하면 카드가 뒷면에서 정면으로 3D로 뒤집히며 대표 영웅 아트가 드러납니다. 매물마다 고정된(같은 매물은 항상 같은) 일반 / 레어 / 레전더리 등급 프레임이 함께 표시됩니다.
- 레전더리 매물이 공개되는 순간에는 화면 전체 플래시 + 파티클 + 전용 팡파레형 사운드가 한 번만 터집니다.
- 등급은 실제 실력이나 랭크를 반영하지 않는 순수 연출용 표시입니다("레전더리 카드" 등 게임적 문구로 표기하며 실력 지표로 오인되지 않도록 했습니다).

### 2. 입찰 = 카드 임팩트 + 연속 입찰 콤보
입찰가가 오를 때마다 금액이 카드에 "꽂히는" 임팩트 애니메이션과 함께 화면이 미세하게 흔들립니다.
- 짧은 시간 안에 입찰이 연속되면 콤보 배지가 올라가고, 콤보 단계가 높을수록 흔들림과 사운드가 더 강렬해집니다.
- 매물이 바뀌거나 한동안 입찰이 없으면 콤보는 자동으로 리셋됩니다.

### 3. 마감 임박 = 불타는 도화선 타이머
마감 5초 전부터 타이머 게이지 끝단에 불꽃과 스파크가 튀고, 게이지 배경에 옅은 연소 느낌이 더해지며, 지지직거리는 크래클 사운드가 함께 재생됩니다. 마감되거나 다음 매물로 넘어가면 즉시 정지합니다.
- 기존 타이머의 접근성 구조(스크린리더 안내, 남은 시간 상태)는 그대로 유지되어 회귀가 없습니다.

### 4. 낙찰 = 골든카드 변신 + 팀보드로 날아가는 입장(flight-in)
낙찰되는 순간 카드가 골드로 변신하고, 해당 팀의 사이드바(팀보드)에 신규 영입 멤버 슬롯이 카드에서 이어지듯 등장합니다. 기존 멤버는 다시 애니메이션되지 않고, 새로 들어온 선수만 입장 연출이 재생됩니다.
- 이 연출은 사용자가 직접 요청한 핵심 기능으로, 개발 중 신규 멤버가 등장하는 바로 그 순간에 애니메이션이 정확히 함께 나타나도록 타이밍 이슈를 한 차례 수정했습니다.

### 5. 효과음 전면 재설계 ("게임처럼 안 들린다" 피드백 반영)
1차 사이클에서 사용자분이 직접 주신 "효과음 좀더 게임처럼 바꿔, 너무 소리가 별론데" 피드백을 반영해, 단일 오실레이터 삐- 톤이었던 효과음을 전부 새로 설계했습니다.
- 신규 에셋이나 npm 패키지 추가 없이 브라우저 Web Audio API만으로 오실레이터 다중 레이어 + 디튠 + 필터 스윕 + 노이즈 버스트 + 리버브를 합성해 타격감과 공간감을 만들었습니다.
- 입찰음: 묵직한 "탁/척" 타격음(콤보에 따라 피치 상승), 낙찰음: 승리 팡파레(아르페지오 + 리버브 테일), 유찰음: 절제된 낙담 톤, 도화선: 신규 지지직 크래클 사운드가 추가됐습니다.
- 기존 사운드 트리거 배선(입찰/낙찰/유찰 이벤트, 모바일 최초 터치 unlock 처리)은 변경하지 않았고, 소켓 연동 코드(`use-auction-socket.ts`)도 건드리지 않아 1차 사이클의 사운드 동작 방식과 충돌 없이 안전하게 확장되었습니다.

### 6. 팀장 화면 모바일 대응 (금요일 경매 대비, feedback-002 반영)
사용자분이 직접 주신 "팀장 화면도 모바일 대응해줘" 피드백을 반영해, 그동안 데스크톱 전용이던 팀장(captain) 화면에 모바일 세로 레이아웃을 추가했습니다. 이제 팀장/감독이 폰으로도 입찰할 수 있습니다.
- 위→아래 세로 스택: 현재 매물 카드 → 입찰 컨트롤 → 채팅. 입찰 컨트롤은 화면 하단에 고정(sticky)되어 채팅을 스크롤하는 중에도 항상 손에 닿습니다.
- 입찰 버튼은 엄지로 누르기 좋은 큰 터치 타겟(80px)으로, 현재가·내 잔여 포인트·정원 마감/최고 입찰자 안내가 함께 표시됩니다.
- 관전자 뷰와 동일한 반응형 분기 방식을 사용해 데스크톱 팀장 화면은 전혀 바뀌지 않았습니다(회귀 없음). 팀 현황/입찰 로그 등 부가 정보는 모바일에서 생략해 입찰에 집중하도록 했습니다.

## 접근성 및 모바일 대응
- 시스템의 "동작 줄이기(prefers-reduced-motion)" 설정이 켜져 있으면 카드 플립, 화면 흔들림, 파티클, 팀보드 flight-in, 타이머 불꽃 애니메이션이 모두 생략되고 정적인 상태 표시로 대체됩니다. 사운드는 시각 연출이 아니므로 이 설정과 무관하게 그대로 재생됩니다.
- 모바일 관전자 화면에서는 팀보드 자체가 노출되지 않으므로 flight-in 연출도 자연히 나타나지 않습니다(설계상 의도된 동작). 나머지 연출(파티클 개수, 화면 흔들림 강도, 플래시 밝기, 타이머 연소 강도)은 데스크톱보다 축소된 강도로 재생됩니다.
- 데스크톱 캡틴 / 마스터 / 관전자 3개 화면은 모두 동일한 컴포넌트를 공유하므로 위 연출이 자동으로 동일하게 반영되며, 기존 화면 동작에 회귀는 없습니다.

## 참고
- 이번 릴리즈는 프론트엔드 전용이며 백엔드는 변경되지 않았습니다.
- 신규 npm 패키지 도입 없음(기존 framer-motion, Web Audio API만 사용). 신규 오디오/이미지 에셋 파일도 추가하지 않았습니다.
- 매물 공개 시 낙찰 순간 스킬 영상을 배경으로 재생하는 기능(검토 항목)은 파일 용량·모바일 성능 부담을 고려해 **이번 사이클에서는 보류**했습니다. 필요 시 별도 사이클에서 재검토합니다.
- 개발 과정에서 코드 리뷰를 통해 팀보드 진입 애니메이션이 한 프레임 늦게 발화되던 문제를 발견해 수정했으며, 그 외 경미한 후속 개선 권고 사항(낙찰 연출 구간의 애니메이션 타이밍 미세 조정, 콤보 만료 타이머의 드문 엣지케이스)은 기능 동작에 지장이 없는 수준으로 남아 있어 다음 사이클에서 다룰 예정입니다.
