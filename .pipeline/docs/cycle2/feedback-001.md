# 피드백 001 — 효과음 품질 개선 (사용자 직접 피드백)

## 원문
"효과음 좀더 게임처럼 바꿔, 너무 소리가 별론데"

## 문제
1차에서 구현된 use-auction-sound.ts의 효과음이 단일 오실레이터 톤(880Hz square 등)이라 8비트 비프음처럼 들림. 게임 수준의 사운드 질감 필요.

## 요구
효과음 유틸을 확장하는 태스크(입찰 콤보 담당)에 사운드 재설계를 포함할 것. 신규 에셋/패키지 없이 Web Audio 레이어링으로 품질을 올린다:

- **공통 기법**: ADSR 엔벨로프(어택/디케이 명확히), 오실레이터 2~3개 레이어링+디튠(두께감), BiquadFilter 스윕(lowpass로 톤 정리), 노이즈 버스트(타격감·화이트노이즈 짧게), ConvolverNode 생성 임펄스로 짧은 리버브 테일(공간감), 미세 랜덤 피치 변주(반복 피로 방지)
- **입찰**: 비프 대신 묵직한 "탁/척" 타격음 — 필터드 노이즈 트랜지언트 + 사인 피치 드롭(200→80Hz), 콤보 시 피치·밝기 상승 유지
- **낙찰**: 승리 팡파레 느낌 — 메이저 코드 아르페지오(3음 순차) + 상단 shimmer + 리버브 테일 길게. 골든카드 연출과 타이밍 동기화
- **유찰**: 낙담 톤 — 마이너 하강 2음 + lowpass 닫힘, 리버브 짧게. 불쾌하지 않게 음량 절제
- **도화선(신규)**: 마감 임박 지지직 크래클(노이즈+하이패스+랜덤 게인 모듈레이션)
- 전체 마스터 게인 정리(클리핑 방지), 이벤트 간 음량 밸런스

## 성공 기준
- "삐-" 계열 원시 톤이 하나도 없을 것. 각 효과음이 타격감/공간감을 가질 것
- 기존 트리거 배선(stageEvent.seq, bidEvents, 모바일 unlock)은 변경 없이 사운드 생성부만 교체
