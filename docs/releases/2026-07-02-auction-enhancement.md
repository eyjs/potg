# 릴리즈 노트 — 경매 고도화 (효과음 / 결과 이미지 / 모바일 관전자 / 로그인 안정화)

- 릴리즈일: 2026-07-02
- 대상: 경매 참여자(캡틴), 마스터, 관전자(모바일 포함) 전원

## 무엇이 좋아졌나

### 1. 실시간 경매 효과음 추가
입찰 / 낙찰 / 유찰 시점마다 구분되는 효과음이 재생됩니다. 입찰음은 짧은 클릭톤, 낙찰음은 상승하는 골드톤, 유찰음은 하강하는 저음으로 오버워치 테마에 맞춘 절제된 사운드입니다.
- 모바일에서는 브라우저 자동재생 정책 때문에 화면을 한 번 터치하기 전까지는 무음이며, 이는 정상 동작입니다.
- 재접속 시 과거 이벤트가 소급 재생되지 않습니다.

### 2. 경매 결과 이미지 다운로드 안정화
"자꾸 실패한다"는 결과 이미지(PNG) 다운로드 문제를 해결했습니다.
- 실패 원인을 진단할 수 있도록 콘솔 로깅을 추가했습니다.
- 폰트가 완전히 로드된 뒤 캡처하도록 개선했습니다.
- 일부 환경에서 이미지 생성을 통째로 실패시키던 크로스 오리진 스타일시트 접근 오류를 원천 차단했습니다.
- 일시적 실패 시 1회 자동 재시도가 동작하며, 그래도 실패하면 명확한 안내 메시지가 표시됩니다.

### 3. 모바일 관전자 전용 화면
모바일에서 경매 화면이 데스크톱 레이아웃 그대로 눌려 보여 사실상 시청이 불가능했던 문제를 해결했습니다. 같은 URL에서 화면 폭에 따라 자동으로 전환됩니다.
- 모바일: 상단에 현재 매물/입찰 현황, 하단에 채팅만 표시되는 트위치/치지직 스타일 세로 시청 화면.
- 데스크톱(`lg` 이상)은 기존 레이아웃이 그대로 유지됩니다(변경 없음).
- 채팅 입력창은 화면 하단에 고정되고, 메시지 영역만 자체 스크롤됩니다.

### 4. 로그인 무한 새로고침 문제 수정
새 브라우저, 시크릿 모드, 사내망 등 신규 환경에서 로그인 시 화면이 로그인↔대시보드를 계속 왕복하며 진입이 불가능했던 심각한 버그를 수정했습니다.
- 원인: 프론트와 백엔드가 서로 다른 도메인이라 인증 쿠키가 "서드파티 쿠키"로 취급되어 최신 브라우저에서 기본 차단되고 있었습니다.
- 조치: 쿠키가 차단된 환경에서는 로그인 응답에 포함된 토큰을 이용해 자동으로 인증을 대체 처리합니다(Authorization 헤더 폴백).
- 기존 방식(쿠키 로그인, 실시간 채팅/경매 소켓 인증)은 그대로 동작하며 회귀가 없습니다.
- 그래도 로그인에 실패하는 경우, 무한 왕복 대신 로그인 페이지에 머무르며 명확한 안내 메시지가 표시됩니다.

## 참고
- 이번 릴리즈는 프론트엔드 위주이며, 로그인 수정 건에 한해 백엔드 인증 모듈(auth)도 함께 변경되었습니다.
- 신규 npm 패키지 도입 없음. 신규 오디오 에셋 파일 없음(Web Audio API 오실레이터 합성 방식).
- 로그인 문제의 근본 해결책(프론트/백엔드 도메인 통일)은 인프라 변경이 필요해 이번 스코프에서 제외되었으며 후속 과제로 남아 있습니다.
